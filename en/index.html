The statistics of my own posts, on my PC.

Pulse Studio is a Windows desktop application. It regularly reads the public statistics of my own videos (views, likes, comments, shares, followers) and shows them in a single dashboard. The history is saved locally, in a SQLite database on the computer.

Pulse Studio is not an online service. It is not sold or distributed, and it has no user accounts. It is used only by its developer, for their own accounts.

This page describes the application to the platforms whose official APIs it uses. Nothing is offered for download.

Platforms

Active

YouTube

Public video and channel statistics through the YouTube Data API v3, with an API key. No account sign-in.

Being set up (sandbox)

TikTok

Read-only sign-in with Login Kit (OAuth): profile, account statistics and public videos (Display API).

Planned

Instagram and Facebook

Instagram professional accounts and Facebook Pages, read-only. Not active yet.

How it works

1. Official sign-in

The account is connected once, on the platform’s official page, opened in the web browser. The permissions requested are minimal and read-only.

2. Regular readings

The application reads public counters from the PC, directly from the official APIs. A temporary drop is only kept once it is confirmed.

3. Local data

The history is stored in SQLite on the PC. Tokens are kept in Windows Credential Manager, never in the database or in the code.

4. Token broker

TikTok requires the token exchange, which uses the app secret, to happen on a server. A small Cloudflare Workers service handles it. It never receives any statistics.

What Pulse Studio does not do

  • It does not post anything, change any account or send any message.
  • It does not read private videos, messages or viewer data.
  • It does not sell or share any data, and shows no ads.
  • It uses no analytics, telemetry or cookies.
