Politique de confidentialité

Dernière mise à jour : 12 novembre 2026 · English version

En bref. Les statistiques sont enregistrées uniquement sur le PC, dans une base SQLite locale. Les jetons d’accès sont gardés dans le Gestionnaire d’identification Windows.

Pour TikTok, un petit serveur (« courtier », Cloudflare Workers) fait l’échange et le renouvellement des jetons, comme TikTok l’exige. Des jetons transitent donc par ce serveur, qui conserve le jeton de renouvellement chiffré. Aucune statistique n’y passe.

Aucune donnée n’est vendue, partagée ou utilisée pour de la publicité.

1. Qui est concerné

Pulse Studio est un logiciel de bureau Windows, personnel, gratuit et non commercial. Il n’est ni vendu ni distribué, et il n’a pas de comptes utilisateurs. Son développeur l’utilise uniquement pour suivre les statistiques de ses propres comptes.

Sur TikTok, l’application fonctionne en mode sandbox : seuls des comptes appartenant au développeur peuvent s’y connecter. Cette politique décrit donc le traitement des données de ces comptes.

Seules les données nécessaires au tableau de bord sont demandées, avec des autorisations en lecture seule.

Ne sont jamais lus : les vidéos privées, les brouillons, les messages, le contenu des commentaires, les données des spectateurs (identité, localisation, âge), l’adresse e-mail, le numéro de téléphone, les contacts. Pulse Studio ne demande aucune autorisation de publication ou de modification.

4. Stockage local

  • Les données ci-dessus sont enregistrées dans une base SQLite sur le PC, dans le dossier de données de l’application (%APPDATA%\com.pulsestudio.app\pulse.db).
  • La base contient les relevés successifs et l’historique stabilisé (une baisse passagère n’est retenue qu’après confirmation), qui servent aux graphiques.
  • La base n’est envoyée à aucun serveur. Les éventuelles sauvegardes sont des copies locales faites par l’utilisateur.

5. Jetons et identifiants

  • Sur le PC, dans le Gestionnaire d’identification Windows : le jeton d’accès TikTok (valable environ 2 heures), la clé d’API YouTube et la clé d’appareil, qui authentifie le PC auprès du courtier.
  • Les jetons ne sont jamais écrits dans la base SQLite, dans les journaux, dans le code source ni dans l’interface.
  • Sur le courtier (voir section 6) : le secret de l’application TikTok, qui n’est jamais présent sur le PC, et le jeton de renouvellement TikTok, chiffré.

6. Courtier Cloudflare

TikTok exige que l’échange du code d’autorisation contre des jetons, ainsi que leur renouvellement, utilise le secret de l’application et se fasse sur un serveur. Pulse Studio utilise pour cela un petit service, le « courtier », hébergé sur Cloudflare Workers (offre gratuite).

Détail
Ce qui transite Pendant la connexion : le code d’autorisation, le vérificateur PKCE et l’adresse de retour locale. Ensuite, les jetons renvoyés par TikTok et l’open_id. Le jeton d’accès est retransmis au PC.
Ce qui est conservé
  • Le jeton de renouvellement TikTok, chiffré en AES-256-GCM et associé à l’open_id.
  • Des identifiants à usage unique (« nonces »), pendant 10 minutes, contre le rejeu de requêtes.
  • Pour Instagram et Facebook, quand ils seront actifs : le résultat de connexion, chiffré, pendant 10 minutes au plus, puis effacé dès que le PC l’a récupéré.
Ce qui n’y passe jamais Les statistiques, les vidéos, leurs titres et l’historique : ils sont lus directement par le PC auprès des API officielles.
Journaux Les journaux d’invocation du courtier sont désactivés, et le code n’écrit rien dans la console. En tant qu’hébergeur, Cloudflare traite les données techniques des requêtes (adresse IP, en-têtes) selon sa propre politique de confidentialité.
État À la date de mise à jour, le courtier est programmé et testé mais pas encore mis en ligne.

7. Services tiers

  • TikTok (open.tiktokapis.com, pages de connexion tiktok.com) et Google / YouTube (googleapis.com) reçoivent les requêtes envoyées par le PC. Ils les traitent selon leurs propres politiques.
  • Cloudflare héberge le courtier.
  • GitHub héberge ce site (voir section 12).

8. Partage et usage

Les données servent uniquement à afficher, sur le PC, l’évolution des statistiques des comptes du développeur. Elles ne sont ni vendues, ni louées, ni partagées. Elles ne servent ni à la publicité ni au profilage, et ne sont pas utilisées pour entraîner des modèles. L’application ne contient ni mesure d’audience, ni télémétrie, ni rapport d’erreurs automatique.

9. Durées de conservation

  • Base locale : jusqu’à ce que l’utilisateur la supprime. Une déconnexion conserve l’historique déjà relevé.
  • Jeton d’accès TikTok : environ 2 heures. Il est remplacé à chaque renouvellement et supprimé à la déconnexion.
  • Jeton de renouvellement TikTok (courtier) : jusqu’à la déconnexion, sa révocation ou son expiration fixée par TikTok.
  • Nonces et résultats de connexion (courtier) : 10 minutes au plus.

10. Déconnexion et suppression

  • « Déconnecter », dans la page Comptes connectés de l’application :
    • le courtier efface d’abord le jeton de renouvellement, puis révoque l’accès auprès de TikTok ;
    • le jeton local est supprimé du Gestionnaire d’identification ;
    • TikTok est mis en pause.
  • L’accès peut aussi être retiré à tout moment depuis les paramètres du compte TikTok, dans la gestion des applications autorisées.
  • Pour supprimer tout l’historique local, il suffit de supprimer le fichier pulse.db, application fermée. L’historique YouTube peut aussi être effacé depuis l’application.

11. Sécurité

  • Toutes les communications réseau sont chiffrées (HTTPS). Seul le retour de connexion TikTok arrive en local, sur http://127.0.0.1, comme TikTok le prévoit pour les applications de bureau.
  • La connexion TikTok utilise PKCE et un paramètre state vérifié.
  • Chaque requête du PC vers le courtier est signée (HMAC-SHA256), horodatée et à usage unique. Le débit est limité.
  • Les autorisations sont minimales et en lecture seule.

12. Ce site web

Ce site est statique et hébergé par GitHub Pages. Il n’utilise ni cookie, ni script, ni mesure d’audience, ni ressource externe. GitHub peut enregistrer des données techniques de visite (par exemple l’adresse IP) selon sa propre déclaration de confidentialité.

13. Modifications et contact

Cette politique sera mise à jour à chaque évolution du traitement des données, notamment avant l’activation d’Instagram et de Facebook. La date de mise à jour figure en haut de la page.

Pour toute question, ouvrez une demande (« Issue ») sur le dépôt GitHub public qui héberge ce site.
