Les statistiques de mes publications, sur mon PC.

Pulse Studio est une application de bureau Windows. Elle relève régulièrement les statistiques publiques de mes propres vidéos (vues, likes, commentaires, partages, abonnés) et les présente dans un tableau de bord unique. L’historique est enregistré localement, dans une base SQLite sur l’ordinateur.

Pulse Studio n’est pas un service en ligne. Il n’est ni vendu ni distribué, et il n’a pas de comptes utilisateurs. Il sert uniquement à son développeur, pour ses propres comptes.

Cette page présente l’application aux plateformes dont elle utilise les API officielles. Elle ne propose aucun téléchargement.

Plateformes

Actif

YouTube

Statistiques publiques des vidéos et de la chaîne via YouTube Data API v3, avec une clé d’API. Aucune connexion de compte.

En configuration (sandbox)

TikTok

Connexion par Login Kit (OAuth) en lecture seule : profil, statistiques du compte et vidéos publiques (Display API).

Prévu

Instagram et Facebook

Comptes professionnels Instagram et Pages Facebook, en lecture seule. Pas encore actifs.

Fonctionnement

1. Connexion officielle

Le compte se connecte une fois, sur la page officielle de la plateforme, ouverte dans le navigateur. Les autorisations demandées sont minimales et en lecture seule.

2. Relevés réguliers

L’application lit les compteurs publics depuis le PC, directement auprès des API officielles. Une baisse passagère n’est retenue qu’une fois confirmée.

3. Données locales

L’historique est stocké en SQLite sur le PC. Les jetons sont gardés dans le Gestionnaire d’identification Windows, jamais dans la base ni dans le code.

4. Courtier de jetons

TikTok exige que l’échange de jetons, qui utilise le secret de l’application, se fasse sur un serveur. Un petit service Cloudflare Workers s’en charge. Il ne reçoit aucune statistique.

Ce que Pulse Studio ne fait pas

  • Il ne publie rien, ne modifie aucun compte et n’envoie aucun message.
  • Il ne lit ni les vidéos privées, ni les messages, ni les données des spectateurs.
  • Il ne vend ni ne partage aucune donnée, et n’affiche aucune publicité.
  • Il n’utilise ni mesure d’audience, ni télémétrie, ni cookie.
